# 🏫 School Management System (Full-Stack Monorepo)

Bu proje; backend tarafında **.NET 8 Web API (Clean Architecture & CQRS)**, frontend tarafında ise **Angular** kullanılarak geliştirilmiş full-stack bir Okul Yönetim Sistemi uygulamasıdır. 

Sistem; Öğrenci ve Öğretmen rollerine göre dinamik arayüzler sunmakta, kurs yönetimini ve kimlik doğrulama süreçlerini güvenli bir şekilde yürütmektedir.
